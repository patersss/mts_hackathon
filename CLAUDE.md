# CLAUDE.md

Решение кейса MTS DevOps Hackathon: kubeadm (одна нода, Ubuntu 24.04) + nginx за Gateway API, Prometheus, Fluentd → Loki. Условие: `Case DevOps (MTC ENGINEER HACK.pdf`.

## Скилы
Всегда используй:
- `ponytail` (https://github.com/DietrichGebert/ponytail) — минимум кода, без лишних абстракций.
- `caveman` (https://github.com/JuliusBrussee/caveman) — коротко в ответах и сообщениях.

Установка, если нет: `npx skills add DietrichGebert/ponytail -g`, `npx skills add JuliusBrussee/caveman -g`.

## Стиль
- Код должен выглядеть написанным человеком. Комментарии только там, где без них непонятно, одна строка.
- Никаких баннеров, эмодзи, «Generated by», пересказа кода в комментариях, длинных docstring.
- README и docs по-русски, сухо и по делу.
- Логику держать в Ansible/Helm/Kustomize, а не в bash. `deploy.sh` только ставит Ansible и запускает playbook.
- Все версии закреплены в `ansible/group_vars/all.yml`.
- Никаких секретов в репозитории: пароли и сертификаты генерируются при деплое.

## Команды
- `make deploy` — полный деплой на чистой Ubuntu 24.04 (под пользователем с sudo).
- `make verify` — smoke-тесты.
- `make lint` — линтеры, те же что в CI.

## Процесс
- Каждый этап в своей ветке `feature/<кратко>` (без слова claude в названии), свой PR, мержит владелец.
- Следующий этап начинать только когда предыдущий проверен (e2e зелёный).
- Коммиты всегда от владельца: `git -c user.name=patersss -c user.email=114485190+patersss@users.noreply.github.com commit ...`. Без трейлеров Co-Authored-By и ссылок на сессии.
- Перед пушем `make lint` должен быть зелёным.
